# 日常音乐操作使用媒体库快照

除扫描、写入和播放外，音乐业务只使用媒体库快照，不检查原文件的存在性、权限或内容。编辑器使用扫描时确认的写入能力，实际保存时重新校验；接受外部修改在重新扫描前不可见，以避免页面操作依赖音乐磁盘。扫描始终重新读取音频内容，不以文件大小或修改时间跳过解析。

数据库只保存内嵌歌词，歌词编辑和下载也只写内嵌歌词。实际播放时读取同目录同名 `.lrc`，有效旁挂歌词优先显示，否则回退到数据库内嵌歌词；旁挂歌词不参与扫描、不入库、不被编辑器展示或修改。当前播放会话保留读取结果，暂停、恢复、跳转位置不重读，切换曲目或重新播放时重读；不预加载旁挂歌词，不增加刷新、来源选择或来源说明。

目录封面在扫描时作为内嵌封面的后备来源导入，共用图片不重复保存；实际使用的缩略图持久化并随原图变化失效。此次调整不提供旧数据库兼容，本机测试数据库直接重置，设置、窗口状态、日志和音乐原文件保留。
